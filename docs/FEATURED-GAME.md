# Featured game widget

Enter StartPage Edit Mode, select an empty panel and add **Featured game**. Open **Appearance > Featured game settings** to configure it.

## Selection

- **Pinned game:** click **Choose pinned game...** and search your library. A removed/missing pinned game shows a prompt; it is not silently replaced.
- **Last played / Recently added:** automatically choose the latest matching game.
- **Random game / Random favorite:** choose a matching game and keep it on page revisits. Click **Another game** to choose a different one when alternatives exist.
- **Selected library game:** follow the game selected in Playnite's library.

Automatic sources can restrict results to installed games and include/exclude hidden games. Explicit pins ignore these automatic filters.

## Presentation and actions

Each instance has its own artwork, content and formatting settings. Choose background or cover artwork (background falls back to cover), image opacity and an overlay color/opacity. Choose description length, title/text size, content width/alignment and optional custom text colors. Theme colors are used until customization is enabled. All color fields use color pickers.

Optional metadata includes playtime, last played, source name/icon and achievement progress. Achievements come from the provider selected in StartPage settings; missing provider data is omitted.

Enable **Play / Install** and **Open in library** buttons as needed. They use Playnite's native actions. Game actions are disabled while editing the dashboard layout. Description HTML is converted to plain text rather than rendered in a browser.

Settings persist with the widget, including dashboard profiles and independent copies. Pinned IDs refer to the current library; reselect a missing pin when importing a profile from another library. Reset featured game settings restores the defaults without changing the panel appearance.


### Metadata formatting

Expand **Metadata formatting** for independent text size, text color and icon size. By default, metadata matches the description text size/color, and icons match the effective metadata text size. Font and icon sizes apply even when custom colors are off.

Uncheck **Use the same size as description text** to use the metadata size field. Uncheck **Use the same color as description text** to choose a separate color (enable **Use custom metadata color**) or retain theme colors. Uncheck **Match icon size to metadata text** to set icon size independently. When matching description color, metadata follows its theme color until custom text colors are enabled.

Under **Artwork and text**, horizontal and vertical content position controls place the title, description, metadata and actions at any of the nine top/center/bottom and left/center/right combinations. The default remains bottom-left.
